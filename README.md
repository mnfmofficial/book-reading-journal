# 📖 Reader's Nook — Book Reading Journal

A clean, warm, self-contained single-page web app to track your books, document deep reflections across rereads, review pooled vocabulary with flashcards, and track actionable insights.

🚀 **Live App:** [https://mnfmofficial.github.io/book-reading-journal/](https://mnfmofficial.github.io/book-reading-journal/)

---

## ✨ Features

- **📚 Library & Reread Tracking:** Group multiple read-through entries under a single book title with side-by-side note comparison across rereads.
- **✏️ Rich Entry Editor:** Live Markdown preview for plot summaries, themes, and key takeaways, plus auto-computed reading duration.
- **🔤 Vocabulary Glossary & Quiz Mode:** Automatic aggregation of new words across all entries, featuring an interactive flashcard quiz mode powered by spaced repetition (interval doubling).
- **✅ Actionable Practice List:** A central checklist pooling all "what to practice" items across every book entry with interactive completion checkboxes.
- **📊 Light Analytics:** Key reading metrics, an interactive GitHub-style reading activity heatmap, and an inline SVG genre breakdown chart.
- **💾 Local Data Persistence & Backup:** Works 100% serverless using `localStorage` with built-in JSON Export and Import capabilities.
- **🎨 Warm Bookish Design:** Cozy typography, parchment aesthetic, fully responsive layout, and dark/light mode support.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (CSS Variables for themes), and JavaScript (ES6+).
- **Libraries:** [Marked.js](https://cdnjs.cloudflare.com/ajax/libs/marked/4.3.0/marked.min.js) (Markdown rendering).
- **Fonts:** [Lora](https://fonts.google.com/specimen/Lora) (Serif headings) & [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Body & UI).
- **Storage:** Browser `localStorage` (No backend required).
